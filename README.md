## 🧑‍💻 Sobre mí

Soy un desarrollador apasionado por construir productos que resuelven problemas reales. Me muevo cómodo tanto en el **front-end** como en el **back-end**, y me encanta explorar tecnologías nuevas — desde apps móviles con React Native hasta bots de Telegram, generadores de CVs con IA, backends para juegos de rol y CLI tools para acelerar mi flujo de trabajo.

- 🔭 **Actualmente trabajo en:** [Blog del Sack](https://github.com/DarkSack/blogdelsack), [DnDBackend](https://github.com/DarkSack/DnDBackend), [create-sackapp](https://github.com/DarkSack/create-sackapp), y varios side-projects más.
- 🌱 **Estoy aprendiendo:** TypeScript avanzado, arquitecturas serverless, Vue.js, Python (Django) y Java.
- 👯 **Busco colaborar en:** proyectos open source, desarrollo web (front y back), y herramientas para creadores de contenido.
- 🤔 **Necesito ayuda con:** bases de datos escalables, patrones NoSQL y arquitectura distribuida.
- 💬 **Pregúntame sobre:** React, Next.js, Expo, TailwindCSS, Supabase, GraphQL o cómo hacer un bot de Twitch 😄.
